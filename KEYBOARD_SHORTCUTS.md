# Keyboard Shortcuts

This document lists all the available keyboard shortcuts in the TabSpace extension.

## Global

| Shortcut            | Action               |
| ------------------- | -------------------- |
| `Cmd+K` or `Ctrl+K` | Focus the search bar |

## Project Navigation

| Shortcut     | Action                      |
| ------------ | --------------------------- |
| `Up Arrow`   | Select the previous project |
| `Down Arrow` | Select the next project     |

## Collection Navigation

| Shortcut            | Action                                                |
| ------------------- | ----------------------------------------------------- |
| `Cmd+E` or `Ctrl+E` | Expand/collapse all collections in the active project |

## Link Navigation

| Shortcut | Action                                      |
| -------- | ------------------------------------------- |
| `1-9`    | Open the corresponding link in a collection |
